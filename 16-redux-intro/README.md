# React Redux Bank

A small banking app built with React and Redux Toolkit to demonstrate how global state can power a real-world UI.

## What it does

This project lets a user:

- create a customer profile with a name and national ID
- view their current balance
- deposit money into the account
- withdraw money from the account
- request a loan with a purpose
- repay an active loan
- convert deposits from different currencies (USD, EUR, GBP) before updating the account balance using a live exchange-rate API

## Tech stack

- React
- Vite
- Redux Toolkit
- React-Redux
- Frankfurter API for currency conversion

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal to use the app.
